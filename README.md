# FMCG Operations Dashboard

An operational analytics dashboard prototype designed to improve inventory visibility, logistics monitoring, and e-commerce reporting workflows in FMCG environments.

---

# Project Overview

This project explores how lightweight automation, reporting dashboards, and operational analytics workflows can support decision-making in FMCG operations and digital transformation environments.

The system integrates warehouse, inventory, inbound/outbound logistics, and e-commerce operational datasets into automated reporting dashboards using Google Sheets, Apps Script, and HTML interfaces.

---

# Business Objectives

- Improve operational visibility
- Monitor inventory movement
- Support logistics reporting workflows
- Track operational KPIs
- Explore consumer purchasing patterns
- Simulate lightweight AI-assisted reporting logic

---

# Dashboard Modules

## 1. Inventory Overview Dashboard
- Inventory health monitoring
- Low-stock alerts
- SKU movement analysis
- ABC inventory analysis

## 2. Logistics Dashboard
- Inbound and outbound tracking
- Supplier monitoring
- Order fulfillment analysis
- Sales channel segmentation

## 3. Stock Accuracy Dashboard
- Inventory adjustment tracking
- Audit visibility
- Operational anomaly identification

## 4. Financial & Management Summary
- Inventory turnover analysis
- Operational KPI reporting
- Sales and inventory relationship tracking

## 5. Consumer Insights Dashboard
- Online sales trends
- Promotion behavior analysis
- E-commerce purchasing patterns
