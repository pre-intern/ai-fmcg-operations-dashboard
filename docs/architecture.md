# System Architecture

## Overview

The dashboard system is designed as a lightweight FMCG operational analytics environment using Google Sheets as the primary data layer and Apps Script for automation logic.

---

# Data Sources

- Inventory dataset
- Warehouse operations
- Inbound logistics
- Outbound orders
- Stock audit records
- E-commerce transaction data

---

# Processing Layer

Apps Script is used for:
- Data cleaning
- KPI aggregation
- Automated refresh workflows
- Trigger-based reporting updates
- Alert generation

---

# Dashboard Layer

HTML dashboards are used to visualize:
- Inventory status
- Logistics activity
- Operational KPIs
- Consumer purchasing trends

---

# Automation Logic

The system supports:
- Scheduled reporting updates
- Real-time dashboard refresh logic
- Low-stock alerts
- Operational anomaly indicators

---

# Goal

The project aims to explore how operational visibility systems can support data-driven decision-making in FMCG and BeautyTech environments.
